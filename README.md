# kevinmartins.nl

Persoonlijke website van Kevin Martins. Pure static HTML/CSS — geen build step.

## Bewerken

- Tekst en links: `index.html`
- Styling: `styles.css`
- Domein voor GitHub Pages: `CNAME` (`kevinmartins.nl`)

Open `index.html` lokaal in je browser om te previewen.

## GitHub Pages

1. Repo Settings → Pages → Source: Deploy from a branch
2. Branch: `main` / root (`/`)
3. DNS voor `kevinmartins.nl` naar GitHub Pages wijzen (A-records of CNAME volgens [GitHub docs](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site))

Huidige live hosting stond op Plesk (`81.169.250.149`). Voor live op dit domein: DNS omzetten naar GitHub Pages, of de bestanden uploaden naar die Plesk-hosting.
